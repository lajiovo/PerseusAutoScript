以下是目前整个项目确立的**极简 AST 节点对照表**。这套结构专为手表端（Vela OS / QuickJS / LVGL）设计，去除了多余的字段名，采用纯列表嵌套，最大程度节省内存：

### 核心 AST 节点对照表

| 节点类型 (`Tag`) | LaTeX / Markdown 示例 | 极简 AST 结构 (`JSON List`) | 说明 |
| --- | --- | --- | --- |
| **`t`** (文本) | `x`, `2H2`, `+`, `CH3COOH` | `["t", "文本内容"]` | 普通文本片段、化学式基础名或纯符号 |
| **`r`** (横向组合) | `a + b` | `["r", node1, node2, ...]` | 水平连续排列的多个节点序列 |
| **`f`** (分式) | `\frac{num}{den}` | `["f", num_node, den_node]` | 分式：包含分子节点、分母节点 |
| **`sq`** (根号) | `\sqrt{x+1}` | `["sq", content_node]` | 根号：包含被开方数节点 |
| **`sup_g`** (上标) | `x^{2}`, `Fe^{3+}` | `["sup_g", base_node, sup_node]` | 上标组合：基底与上标内容 |
| **`sub_g`** (下标) | `H_{2}`, `a_{1}` | `["sub_g", base_node, sub_node]` | 下标组合：基底与下标内容 |
| **`vec`** (向量) | `\vec{a}` | `["vec", content_node]` | 向量符号：在顶部自动渲染小箭头 |
| **`chem_seq`** (化学序列) | 完整化学方程式 | `["chem_seq", [node1, node2, ...]]` | 化学方程式容器，内部可混合化学式与箭头 |
| **`chem_a`** (化学箭头) | `->[点燃]`, `\xlongequal{\Delta}` | `["chem_a", "符号", top_node, bot_node]` | 带条件的化学反应箭头（符号、上方条件、下方条件） |
| **`m`** / **`txt`** | 段落 / 换行符 | `["m", ...]` / `["txt", "\n"]` | 顶层排版容器与行间换行控制 |

---

### 💡 典型示例对照

#### 1. 分式与上标：$\frac{1}{2}x^2$

```json
[
  "r",
  ["f", ["t", "1"], ["t", "2"]],
  ["sup_g", ["t", "x"], ["t", "2"]]
]

```

#### 2. 化学方程式：$2H_2 + O_2 \xrightarrow{点燃} 2H_2O$

```json
[
  "chem_seq",
  [
    ["t", "2H2"],
    ["t", " + "],
    ["t", "O2"],
    ["chem_a", "→", ["t", "点燃"], null],
    ["t", "2H2O"]
  ]
]

```
