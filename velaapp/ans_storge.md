根据前面代码中增量同步中心（`sync.ux`）与阅读器（`reader.ux`）对数据的处理逻辑，离线存储在本地 `storage` 中 `local_answers` 键下的数据结构是一个**题目对象数组**。其中每一道题目的结构、分页以及内容均完全符合项目的**极简 AST 节点对照表**规范。

以下是完整的离线存储数据结构详细说明与示例：

### 1. 整体存储结构 (`local_answers`)

本地存储的根节点是一个 JSON 数组，包含所有已下载并同步的题目解析：

```json
[
  {
    "id": "ans_001",
    "title": "高三数学函数导数专项练习解析",
    "total_pages": 2,
    "pages": [
      {
        "blocks": [ /* 第一页的极简 AST 区块列表 */ ]
      },
      {
        "blocks": [ /* 第二页的极简 AST 区块列表 */ ]
      }
    ]
  },
  {
    "id": "ans_002",
    "title": "化学反应原理与平衡常数计算",
    "total_pages": 1,
    "pages": [
      {
        "blocks": [ /* ... */ ]
      }
    ]
  }
]

```

---

### 2. 单个题目对象（Item）字段说明

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `id` (或 `ans_id`) | String / Number | 题目的唯一标识符（在同步时会自动统一转换为 `id`） |
| `title` | String | 题目标题，会在阅读界面顶部固定栏 (`top-bar`) 展示 |
| `total_pages` | Number | 总页数 |
| `pages` | Array | 页面数据列表，每一项代表一页，包含该页的所有极简 AST 区块数组 `blocks` |

---

### 3. 页面内区块（Blocks）与极简 AST 对照结构

每一页的 `blocks` 数组中的每个元素都经过 `normalizeItemAst` 清洗，严格遵循**极简 AST 节点对照表**：

* **标题节点**：
`["h1", "文本内容"]`、`["h2", "文本内容"]`、`["h3", "文本内容"]`
* **段落/容器节点** (`m`)：
`["m", 节点1, 节点2, ...]`（内部可混合各种内联文本、公式或子组件）
* **基础文本节点** (`t` / `txt`)：
`["t", "文本内容"]`


* **横向组合节点** (`r`)：
`["r", 节点1, 节点2, ...]`


* **分式节点** (`f`)：
`["f", 分子节点, 分母节点]`


* **根号节点** (`sq`)：
`["sq", 被开方数节点]`


* **上标组合** (`sup_g`)：
`["sup_g", 基底节点, 上标节点]`


* **下标组合** (`sub_g`)：
`["sub_g", 基底节点, 下标节点]`


* **向量符号** (`vec`)：
`["vec", 内容节点]`


* **化学方程式序列** (`chem_seq`)：
`["chem_seq", [节点1, 节点2, ...]]`


* **带条件的化学反应箭头** (`chem_a`)：
`["chem_a", "符号", 上方条件节点, 下方条件节点]`



---

### 4. 离线存储数据完整示例

以下是一个具体的题目离线存储 JSON 实例，包含分式、上标及化学方程式：

```json
[
  {
    "id": "math_chem_demo_1",
    "title": "综合解析示例",
    "total_pages": 1,
    "pages": [

        "blocks": [

          [
            "m",
            ["t", "已知表达式为 "],
            ["f", ["t", "1"], ["t", "2"]],
            ["sup_g", ["t", "x"], ["t", "2"]]
          ],
          ["h1", "二、 化学反应方程式"],
          [
            "m",
            [
              "chem_seq",
              [
                ["t", "2H2"],
                ["t", " + "],
                ["t", "O2"],
                ["chem_a", "→", ["t", "点燃"], null],
                ["t", "2H2O"]
              ]
            ]
          ]
        ]
      }
    ]
  }
]

```
